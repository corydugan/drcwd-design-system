# drCWDugan design system repository

The brand book is the drCWDugan design system in Claude: https://claude.ai/artifact/2DDLTKvVQHHDpZ3PKbZngF

Its files sit here, in `design-system/project/`, and they are what gets edited:

- `README.md`, the brand book: the twelve rules, colour, surfaces, typography with the card scale, cards, carousels, Google Business Profile, video, logo, iconography
- `tokens.json`, every colour, type, spacing and surface value
- `assets/Logos/README.md`, the lockups and when each is used
- `design-system.json`, the index of every logo and motion upload

## The edit path

1. Edit `design-system/project/`.
2. Publish the changed files to the design system.
3. Run `python3 ~/.claude/scripts/brand_tokens.py build`.

## Generated files

- `colors_and_type.css`: every value that `design-system/project/tokens.json` holds; the renderers and previews read it
- `tokens.json`: the repository token tree, rebuilt from the stylesheet by `scripts/build_tokens.py`
- `README.md` and `PASTE-INTO-TOOLS.md`: these two pointers

`python3 ~/.claude/scripts/brand_tokens.py check` exits 1 when any of them is out of date.

The logo files are in `logo/`, copied from the design system's uploads.
