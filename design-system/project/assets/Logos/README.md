# Logos

The delta and its lockups, outlined to paths (no font dependency). Every file is single-ink and its ink is literal, named below. An `<img>` cannot inherit colour, so each surface has its own file.

| File | Use |
|---|---|
| `drCWDugan lockup paper_10312026_CD.svg` | Delta + "drCWDugan" in DM Serif Display, grape-800. Cards on paper. |
| `drCWDugan lockup ink_10312026_CD.svg` | The same in white. Cards on ink, and the mark in the video sign-off. |
| `Dr Cory Dugan lockup paper_10312026_CD.svg` | Delta + "Dr Cory Dugan", no full stop, grape-800. The website, documents and letters to clients. |
| `Dr Cory Dugan lockup ink_10312026_CD.svg` | The same in grape-200, the ink colour Cory set for this lockup on 27 October 2026. |
| `Dr Cory Dugan credential lockup paper_10312026_CD.svg` | Credential lockup: delta + "Dr Cory Dugan, PhD", grape-800. Workplaces and proposals. |
| `Dr Cory Dugan credential lockup ink_10312026_CD.svg` | The same in grape-200. |
| `Dr Cory Dugan stacked lockup paper_10312026_CD.svg` | Stacked lockup for square and narrow spaces, grape-800. |
| `Dr Cory Dugan stacked lockup ink_10312026_CD.svg` | The same in grape-200. |
| `icon-delta.svg` | Icon: white delta on a grape-800 rounded tile (rx 22 on 96). Avatar, app icon, favicon down to 24px. |
| `icon-delta-inverse.svg` | Icon for light grounds: grape-800 delta on a white tile with an `ink-200` hairline edge. |
| `lockup-primary-delta-outlined.svg` | Superseded on 31 October 2026 by the Dr Cory Dugan lockup; it carries the full stop. Kept for the record. |
| `lockup-credential-delta-outlined.svg` | Superseded on 31 October 2026 by the Dr Cory Dugan credential lockup; it carries the full stop. Kept for the record. |
| `wordmark-stacked-delta-outlined.svg` | Superseded on 31 October 2026 by the Dr Cory Dugan stacked lockup; it carries the full stop. Kept for the record. |

- Clearspace at least the delta's height on every side; minimum wordmark width 150px / 25mm.
- Never stretch or rotate the delta, add a gradient, recolour outside grape, ink or paper, place on an un-scrimmed photo, or add a baseline rule under the name.
- The 31 October files were outlined with fontTools from DM Serif Display, with the font's own kerning, on the original geometry: delta at 32,38 9,80 55,80, text from x 76 on a baseline of 80 at 64px.
